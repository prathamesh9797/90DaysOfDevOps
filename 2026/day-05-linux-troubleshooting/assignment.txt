>>>>    **Environment basics (2):** `uname -a`, `lsb_release -a` (or `cat /etc/os-release`)  

Prints all system information in one line:
Kernel name (Linux)
Hostname
Kernel release & version
Machine hardware (x86_64, arm64, etc.)
OS/architecture

prathamesh@localhost:~$ uname -a
Linux localhost 6.14.0-37-generic #37~24.04.1-Ubuntu SMP PREEMPT_DYNAMIC Thu Nov 20 10:25:38 UTC 2 x86_64 x86_64 x86_64 GNU/Linux

lsb_release -a or cat /etc/os-release
