-    The core components of Linux (kernel, user space, init/systemd)
>>  Kernel >> is the heart of the linux OS
    Its a Onion like structure ASK outermost layer is application > Shell > kernel > Hradware
    only Kernel directly interacts with hardware, it is the first part loaded during boot
    and remains in memory until shutdown.

    Responsibilities > Memory Management , Device Management , File System Management
                        Networking

    User Space >> is where users and applications run ,
                    programs here cannot access hardware directly

        User space Includes Shells > ex.> bash,zsh,shutdown
                            System Libraries, core utilities( ls,cp,mv,grep,cat)
                            Applications (editors , browsers, servers,containers)
                            
        User space ensures security and stability by isolating applications from Hradware
